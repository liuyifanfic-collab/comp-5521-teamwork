# 前端本地测试用例（双链 Mock）

在本地两条 Hardhat 链上手动跑一遍完整流程：一次成功交换、一次双边超时退款，中间穿插合约应当拒绝的无效操作。全部在一个浏览器里完成，用 `?devwallet` 切换 Alice / Bob，不需要 MetaMask 和测试币。

预计用时：约 10 分钟（用例 2 需要等两个 timelock 到期）。

## 0. 准备环境

在仓库根目录 `comp-5521-teamwork/` 下，开 4 个终端，按顺序执行。

**终端 1：链 A（模拟 Ethereum Sepolia，chainId 31337）**

```bash
CHAIN_ID=31337 npx hardhat node --config frontend/dev/hardhat.local.config.cjs --port 8545
```

**终端 2：链 B（模拟 Arbitrum Sepolia，chainId 31338）**

```bash
CHAIN_ID=31338 npx hardhat node --config frontend/dev/hardhat.local.config.cjs --port 8546
```

**终端 3：部署合约**（两条链都启动后再执行）

```bash
npx hardhat compile && node frontend/dev/deploy-local.cjs
```

预期输出 `Deployed. Config written to frontend/src/config.local.json`，并打印两条链上的 ERC20HTLC、MST、ETHHTLC 地址。

**终端 4：前端**

```bash
cd frontend && npm run dev
```

浏览器打开 <http://localhost:5173/?devwallet>。

**检查点**

- [ ] 顶栏显示「本地双链 Mock」，左侧下拉框是 `Alice 0xf39f…2266`，网络开关停在「MST 链」。
- [ ] 概览里 Alice 的 MST 余额是 1000000 MST，两条链上的 ETH 都约为 10000。
- [ ] 进度条 5 个节点都没完成，「交换流程」停在 Alice 第 1 步。
- [ ] 如果页面里还留着上一次的 swap，点「开始新的交换（清空本地会话）」。

> 重启 Hardhat 节点后链上数据会清空：要重新执行终端 3 的部署，并在页面上点「开始新的交换」。

账户约定（Hardhat 默认测试账户，节点已解锁，页面不接触私钥）：

| 角色 | 地址 | 初始资产 |
|---|---|---|
| Alice | `0xf39f…2266`（账户 #0） | 1,000,000 MST、两条链各 10000 ETH |
| Bob | `0x7099…79c8`（账户 #1） | 1,000 MST、两条链各 10000 ETH |

切换角色：点「交换流程」卡片右上角的 Alice / Bob 标签，钱包账户会自动跟着切换。

## 用例 1：成功交换（含 4 个无效操作）

参数：Alice 锁 10 MST，T1 = 4 分钟；Bob 锁 0.01 ETH，T2 = 2 分钟。

时间要求：第 1.8 步 Bob 核验时，T1 至少还剩 45 秒；第 1.11 步锁定 ETH 后，要在 2 分钟内完成 1.13–1.14（Alice 领取 ETH），之后 Bob 要在 T1 到期前完成 1.16。按顺序连续做下来时间很宽裕。

### Alice：创建 MST 锁

| # | 操作 | 预期结果 |
|---|---|---|
| 1.1 | 选 Alice 标签，点「生成新的 secret」 | secret 和 hashlock 从乱码逐字解密成十六进制；第 1 步显示「完成」；进度条节点 1 画出绿色对勾 |
| 1.2 | 保持默认：Bob 地址 `0x7099…`、数量 10、T1 = 4，点「① approve」 | 交易记录出现一条，图标从虚线圈变成绿色对勾；「MST 已授权」变为 10 MST |
| 1.3 | 点「② 锁定 MST」 | 交易确认；右侧出现 MST 锁卡片，状态「锁定中 · 可领取 Claimable」，倒计时约 4 分钟；进度条节点 2 打勾；第 3 步高亮，边框扫过一圈光；Alice 的 MST 余额滚动到 999990 |

### 无效操作 1：到期前退款

| # | 操作 | 预期结果 |
|---|---|---|
| 1.4 | 看 MST 锁卡片上的「长按退款」 | 按钮是灰的，旁边写「退款：尚未到期，不能退款」 |
| 1.5 | 点卡片下方的「仍然尝试退款」 | 交易记录出现一条失败记录（红叉）：`SwapNotExpired：尚未到期，不能退款`；右下角弹出同样的提示；锁仍是 Active |

### 无效操作 2：非收款人领取

| # | 操作 | 预期结果 |
|---|---|---|
| 1.6 | 仍是 Alice，点 MST 锁卡片上的「仍然尝试领取」，在弹出框里粘贴第 1.1 步的 secret | 失败：`UnauthorizedReceiver：只有指定收款人才能领取`（收款人是 Bob，Alice 不能领取自己锁的 MST） |

### Bob：核验并创建 ETH 锁

| # | 操作 | 预期结果 |
|---|---|---|
| 1.7 | 切到 Bob 标签。MST swapId 已自动填好；在「约定 MST 数量」填 **20**，点「读取并核验」 | 清单里「锁定金额 ≥ 约定金额」显示红色 ✘；「锁定 ETH」按钮不可点 |
| 1.8 | 把约定数量改成 **10**，再点「读取并核验」 | 6 项全部是绿色 ✔；第 1 步「完成」；「锁定 ETH」可点 |

### 无效操作 3：T2 不早于 T1

| # | 操作 | 预期结果 |
|---|---|---|
| 1.9 | 把「T2：多少分钟后到期」改成 **5** | 提示变红：`✘ 需比 T1 至少早 30s` |
| 1.10 | 点「锁定 ETH」 | 弹出提示 `T2 必须比 T1 至少早 30s…`，**不发交易**，交易记录没有新增 |
| 1.11 | 把 T2 改回 **2**，点「锁定 ETH」 | 交易确认；右侧出现 ETH 锁卡片，hashlock 与 MST 锁完全相同；进度条节点 3 打勾 |

### 无效操作 4：错误的 secret

| # | 操作 | 预期结果 |
|---|---|---|
| 1.12 | 仍是 Bob，点 MST 锁卡片上的「仍然尝试领取」，输入 `0x` 加 64 个 `1` | 失败：`InvalidSecret：secret 不正确：keccak256(secret) ≠ hashlock` |

### Alice：核验 ETH 锁并领取

| # | 操作 | 预期结果 |
|---|---|---|
| 1.13 | 切到 Alice 标签。ETH swapId 已自动填好；「约定 ETH 数量」填 0.01，点「读取并核验」 | 7 项全部 ✔，其中包括「hashlock 与 MST 锁一致」和「T2 < T1」 |
| 1.14 | 点「领取 ETH」 | 交易确认；ETH 锁变为「已领取 Claimed」；进度条节点 4 打勾；secret 此时公开在链 B 的 Claimed 事件里 |

### Bob：取得 secret 并领取 MST

| # | 操作 | 预期结果 |
|---|---|---|
| 1.15 | 切到 Bob 标签，等 3 秒左右（或点「读取 secret」） | 第 3 步显示「已取得 secret（keccak256 校验通过）」，secret 逐字解密出现，和 1.1 步的值一致 |
| 1.16 | 点「领取 MST」 | 交易确认；MST 锁变为「已领取 Claimed」；Bob 的 MST 余额从 1000 滚动到 1010 |

### 最终检查

- [ ] 双链状态顶部出现绿色横幅「✔ 交换完成：两条链上的锁均已领取」，文字上有扫光。
- [ ] 进度条 5 个节点全部是绿色对勾。
- [ ] 余额：Alice 999990 MST、链 B 上约 10000.01 ETH（扣少量 gas）；Bob 1010 MST、链 B 上约 9999.99 ETH。
- [ ] 交易记录里失败记录是红叉，其余全是绿色对勾。

## 用例 2：双边超时退款

参数：Alice 锁 5 MST，T1 = 3 分钟；Bob 锁 0.01 ETH，T2 = 1 分钟；双方都不领取。

| # | 操作 | 预期结果 |
|---|---|---|
| 2.1 | 点「开始新的交换（清空本地会话）」并确认 | 两张锁卡片回到「未创建」，进度条清空，横幅消失 |
| 2.2 | Alice：生成 secret；数量填 5、T1 填 3；approve，然后锁定 MST | MST 锁 Active，倒计时约 3 分钟 |
| 2.3 | Bob：读取并核验（全部 ✔）；T2 填 1，锁定 ETH | ETH 锁 Active，倒计时约 1 分钟 |
| 2.4 | 仍是 Bob，在 ETH 锁卡片上点「仍然尝试退款」 | 失败：`SwapNotExpired：尚未到期，不能退款` |
| 2.5 | 等到 ETH 锁倒计时变成「已过期」 | ETH 锁状态变为「已过期 · 可退款 Refundable」 |

### 无效操作 5：过期后领取

| # | 操作 | 预期结果 |
|---|---|---|
| 2.6 | 切到 Alice，在 ETH 锁卡片上点「仍然尝试领取」 | 失败：`SwapExpired：已过期，不能再领取（只能由发送方退款）`；卡片上的「领取」按钮是灰的，原因写「已过期，不能领取」 |

### Bob 退回 ETH

| # | 操作 | 预期结果 |
|---|---|---|
| 2.7 | 切到 Bob，在 ETH 锁卡片上**轻点一下**「长按退款」 | 不发交易，交易记录不变 |
| 2.8 | 按住「长按退款」，红色填到一半时松手 | 填充回退，不发交易 |
| 2.9 | **按住**「长按退款」约 1.2 秒，直到红色填满 | 按钮显示「已提交」并发出退款交易；ETH 锁变为「已退款 Refunded」；出现黄色横幅「↩ 交换未完成，已退款：ETH 已退回 Bob」；进度条节点 4 显示 ↩ |

### Alice 退回 MST

| # | 操作 | 预期结果 |
|---|---|---|
| 2.10 | 等到 MST 锁也过期（T1，约再等 2 分钟），切到 Alice | MST 锁变为「已过期 · 可退款」，「长按退款」可用 |
| 2.11 | 按住「长按退款」直到填满 | MST 锁变为「已退款」；横幅变成「MST 已退回 Alice，ETH 已退回 Bob」；进度条节点 4、5 都显示 ↩ |
| 2.12 | 查看两张已退款的锁卡片 | 不再显示领取、退款按钮和「仍然尝试」链接：终态不提供任何操作（重复退款由合约以 `SwapNotActive` 拒绝，已由 A/B 的单元测试覆盖） |

最终检查：

- [ ] Alice 的 MST 回到退款前的数值（只多花了 gas 对应的 ETH）。
- [ ] Bob 链 B 上的 ETH 回到锁定前的数值（扣少量 gas）。

## 可选：用 MetaMask 代替 dev wallet

1. 打开 <http://localhost:5173/>（不带 `?devwallet`）。
2. 在 MetaMask 里导入 Hardhat 账户 #0 和 #1（私钥在终端 1 启动时打印，是公开的测试私钥，**只能用于本地链**），由你自己在 MetaMask 中操作。
3. 点「连接钱包」，再点「MST 链」/「ETH 链」；钱包里没有这两条本地链时，页面会请求添加（RPC `http://127.0.0.1:8545` / `8546`，chainId 31337 / 31338）。
4. 切换 Alice / Bob 时需要在 MetaMask 里手动切换账户。
5. 如果重启了 Hardhat 节点，MetaMask 可能报 nonce 错误：在 MetaMask「设置 → 高级 → 清除活动标签数据」后重试。
